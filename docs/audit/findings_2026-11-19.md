# Findings, 2026-11-19 (CIC-IDS2017 Improved, dev analysis, not final paper results)

## Setup
- Split: Attempted rows dropped, float32 dedup, per-class time blocks (tests: tests/test_split.py).
- Attack: forward-only pad (data packets) + delay, validity-checked, eps 1.0; std/variance recomputed exactly (ddof=1).
- Models: XGBoost A (all features minus headers) and B (no TCP flags). Explanations: XGBoost pred_contribs on the
  best-iteration trees (0..331); verified equal to predict_proba scores (1e-5).

## Results
1. Detection is near-perfect (AUC 1.0) but A leans ~85% on TCP flags (rst_flag_count alone ~70% of gain).
2. Evasion is rare: A 159/60,123 detected (0.26%), B 220/60,063 (0.37%). Concentrated in Slowhttptest, Slowloris,
   Portscan, Infiltration-Portscan. The attack moves features carrying only ~4% of A's gain.
3. Threshold tuning catches most evasions. A: 87.4% at t=0.05 (0.014% benign flagged), 93.7% at t=0.01 (0.047%).
   B: 77.7% at t=0.05 (0.052%), 89.1% at t=0.01 (0.154%).
4. SHAP shift is ~10x larger on evaded flows (L1 5.2 vs 0.54), but this is partly mechanical (evaded = score crossed 0.5).
5. Reference-free instability (noise 0.05, 30 copies) vs overlapping-score benign negatives: score-only AUC A 0.932 / B 0.893;
   gain from adding instability A +0.053 [0.022, 0.087], B +0.082 [0.062, 0.104]. Positive at all 3 noise levels.
   NOTE: negatives were chosen after a saturated first test (score-only AUC 1.000 vs typical benign); disclose as post hoc.
6. Confound check (model A): the CLEAN versions of the same flows are as unstable as the adversarial ones
   (median log-instability 2.978 vs 2.944; benign 2.668; AUC vs benign 0.938 vs 0.918). Adversarial is more unstable than its
   own clean version in only 20.1% of flows. => instability tracks attack-likeness, not evasion. H2 NOT supported as an
   evasion-specific detector.
